# Short-Form Patterns

## Pattern 1: Prompt to Proof

Use when the main claim is "one prompt created this."

- 0-2s: Remotion prompt box types the exact prompt.
- 2-5s: Cut to final output proof.
- 5-14s: Show three animated steps: context, files, render.
- 14-22s: Show real demo clip proving one step.
- 22-27s: CTA card.

Remotion scenes:

- typed prompt with blinking cursor
- progress chips: `Website`, `Storyboard`, `Scenes`, `Voice`, `Render`
- proof window with real B-roll inside a framed panel

## Pattern 2: Small Version / Bigger Version

Use when reframing how the tool should be understood.

- 0-2s: "Most people use this like a chatbot."
- 2-6s: show plain chat prompt as the small version.
- 6-14s: animate the tool taking actions across files, browser, plugins.
- 14-22s: show real demo clips for one or two actions.
- 22-28s: CTA.

Remotion scenes:

- left/right comparison
- checkmarks for `Browse`, `Create`, `Run`, `Render`
- tool icons/chips moving into a workflow line

## Pattern 3: Stack Reveal

Use when the value is the tool combination.

- 0-2s: show the final output.
- 2-7s: reveal the stack as four animated cards.
- 7-17s: show what each tool does.
- 17-24s: show real proof clip.
- 24-30s: CTA.

Remotion scenes:

- cards for `Codex`, `HyperFrames`, `Remotion`, `ElevenLabs`
- animated arrows from input to final output
- final CTA card with keyword

## Pattern 4: Mistake / Fix

Use when teaching a production rule.

- 0-2s: name the mistake.
- 2-6s: show why the old method fails.
- 6-18s: show the better workflow.
- 18-25s: show the payoff.
- 25-30s: CTA.

Remotion scenes:

- red "wrong" label, green "better" label
- before/after timeline
- highlighted rule card

## Minimum Acceptance Checklist

- Hook is understandable with the sound off.
- Value is more than "look what I made."
- At least one real demo/proof shot appears.
- At least one new Remotion-created teaching moment appears.
- Captions are generated from the final audio and are readable on mobile.
- Caption placement does not cover the proof, prompt box, cursor, or CTA.
- CTA appears on screen and is spoken or strongly implied.
- The short can stand alone without the long-form video.
